# fixtures

`vault-demo/` est un petit vault d'exemple : une page avec tous les types de blocs, une arborescence à trois niveaux, une page en mode liste, un ordre manuel et une note externe non importée.

La page « Bienvenue » garde exprès une citation et un séparateur, que l'application ne crée pas : ils vérifient qu'un fichier qui en contient est affiché et réécrit sans rien perdre.

Il sert aux tests et aux essais de l'application. Ne pas l'ouvrir directement comme vault de travail : en faire une copie, sinon les essais modifient les fichiers versionnés.
