# Recette J0 : socle et preuve SMB

Critère de sortie : fenêtre ouverte sous Linux, fichier test écrit et relu sur le NAS en SMB 3 depuis le poste.

Ce qui est déjà vérifié sans NAS : la fenêtre s'ouvre (en développement et depuis l'AppImage), l'application lance le binaire compagnon embarqué, un NAS injoignable est signalé proprement, le mot de passe est enregistré chiffré. Il reste ce qui demande le NAS réel.

## 1. Lancer l'application

```bash
npm install
npm run dev
```

Ou l'AppImage, pour tester ce qui sera vraiment installé :

```bash
npm run package
./apps/desktop/release/Notes-0.1.0-x86_64.AppImage
```

## 2. Tester la connexion

Remplir le formulaire « Connexion au NAS » (adresse, partage, dossier du vault, utilisateur, mot de passe), puis « Enregistrer et tester ».

Attendu :

- le bandeau vert « Connexion réussie » ;
- cinq étapes avec leur durée : connexion, dossier du vault, écriture, relecture, suppression ;
- la ligne « SMB 3.1.1, messages signés, N réponses chiffrées sur N », avec les deux nombres égaux ;
- sur le NAS, le dossier du vault existe et ne contient aucun fichier `.notes-test-*`.

## 3. Vérifier les refus

| Manipulation | Attendu |
|---|---|
| Mauvais mot de passe, puis tester | « Échec du test », identifiants refusés |
| Nom de partage inexistant | « Échec du test », partage introuvable |
| Adresse d'une machine éteinte | « Échec du test », NAS injoignable, après quelques secondes |

Remettre ensuite les bons réglages.

## 4. Vérifier le mot de passe

- Fermer puis relancer l'application : les réglages sont là, le champ du mot de passe est vide et l'aide indique qu'un mot de passe est enregistré. Le test passe sans le ressaisir.
- Le mot de passe n'apparaît en clair dans aucun fichier de l'application :

```bash
grep -rl "TON_MOT_DE_PASSE" ~/.config/ 2>/dev/null
```

La commande ne doit rien afficher (à lancer dans un terminal dont l'historique ne te gêne pas, ou précédée d'une espace).

- « Oublier le mot de passe » le retire : le test demande alors de le saisir.

## 5. Facultatif : test d'intégration du compagnon

Plus complet que le bouton (dossiers imbriqués, renommage, liste, erreurs attendues). Le mot de passe est demandé au clavier.

```bash
cd apps/smb-companion
NOTES_NAS_HOTE=<adresse> NOTES_NAS_PARTAGE=<partage> NOTES_NAS_UTILISATEUR=<utilisateur> \
  go test -tags nas -count=1 -v ./internal/smbfs/
```

Attendu : `PASS`, avec la ligne « réponses chiffrées : N sur N ».
