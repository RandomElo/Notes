# Recette J6 : blocs riches

Critère de sortie : une page technique complète, rédigée confortablement.

Ce qui est déjà vérifié par les tests automatiques : la lecture et l'écriture sans perte des tableaux, images et callouts (cas écrits à la main et textes tirés au hasard), un tableau ou un callout non modifié qui garde son texte d'origine, le nom et la nature des images copiées, la liste des images inutilisées, le protocole qui ne sert que les images du dossier des notes. Dans l'application, sur une copie du vault d'exemple : une page rédigée au clavier avec code, tableau, callout et image collée, l'ouverture de la page Bienvenue sans rien y changer, les poignées du tableau, le bouton « Copier ». Il reste ce qui ne se juge qu'à l'usage : le confort.

Tout se fait sur le PC, sans NAS.

## 0. Préparer

Une copie du dossier des notes, au cas où :

```bash
cp -a ~/Notes ~/Notes.avant-j6
```

Lancer l'application (`npm run dev`). La barre de titre doit afficher la version 0.5.9. Créer une page « Essai J6 » pour la suite.

## 1. Bloc de code

| Manipulation | Attendu |
|---|---|
| Taper `/code`, `Entrée`, puis quelques lignes de TypeScript | Un bloc de code, avec une barre « Texte brut » et « Copier » au-dessus |
| Cliquer « Texte brut », taper `ts`, `Entrée` | La barre affiche « TypeScript », le code se colore aux couleurs du thème |
| Dans le code, `Tab` puis `Maj+Tab` | Deux espaces ajoutées puis retirées en début de ligne. Le curseur ne sort pas du bloc |
| Créer un bloc de code vide (`/code`) et y coller un morceau de Python ou de JSON copié ailleurs | Le langage se met tout seul (Python, JSON) |
| Cliquer « Copier », puis coller dans un éditeur de texte | « Copié » s'affiche un instant. Le texte collé est le code, sans numéros |
| Dans les réglages, « Modifier le thème », « Autres réglages », section Code : cocher « Numéros de ligne » et « Retour à la ligne » | Les lignes sont numérotées dans la marge. Une ligne trop longue passe à la ligne, sa suite alignée sur son texte |
| Trois fois `Entrée` à la fin du code | Le curseur sort du bloc |

## 2. Tableau

| Manipulation | Attendu |
|---|---|
| Taper `/tableau`, `Entrée` | Une grille s'ouvre, 3 × 3 en surbrillance (la première ligne est l'en-tête) |
| Survoler une autre taille et cliquer, ou choisir aux flèches puis `Entrée` | Le tableau a cette taille, le curseur est dans la première cellule |
| Remplir au clavier : `Tab`, `Maj+Tab`, `Ctrl+↑/↓` | On passe de cellule en cellule. `Tab` dans la dernière cellule ajoute une ligne |
| `Entrée` dans une cellule | Le curseur descend d'une cellule. Sous la dernière ligne, une ligne est ajoutée |
| `Ctrl+→` bref, puis `Ctrl+→` tenu | Bref : un mot plus loin. Tenu : la cellule suivante, puis une de plus à chaque instant |
| Cliquer la poignée « + » à droite du tableau, puis celle du bas | Une colonne, puis une ligne de plus |
| Tirer la poignée de droite vers la droite, puis la ramener vers la gauche | Des colonnes apparaissent pendant le geste, puis disparaissent. Une colonne qui contient du texte ne disparaît jamais |
| Dans la barre d'outils d'une cellule : menu « Tableau » (ligne, colonne, supprimer) et les trois alignements | Chaque action fait ce qu'elle dit. L'alignement vaut pour toute la colonne |
| Depuis la dernière ligne, `↓`, puis taper du texte | Le texte s'écrit sous le tableau |
| Ouvrir `page.md` de la page dans un éditeur de texte | Le tableau est lisible : colonnes alignées par des espaces, `:-:` ou `--:` pour une colonne centrée ou à droite |

## 3. Image

| Manipulation | Attendu |
|---|---|
| `/image`, choisir une ou deux images sur le disque | Elles apparaissent dans la page. Le dossier de la page contient `assets/` avec leurs copies (nom sans espaces) |
| Faire une capture d'écran (`Impr. écran` vers le presse-papiers), la coller dans la page | Elle apparaît, copiée sous le nom `image-AAAA-MM-JJ-HHMMSS.png`, à l'heure du poste |
| Glisser une image depuis le gestionnaire de fichiers dans la page | Elle apparaît là où elle a été déposée |
| Cliquer une image : barre au-dessus. Essayer 33 %, 66 %, 100 %, et les trois alignements | La taille et la place changent tout de suite |
| Bouton des textes : remplir texte alternatif et légende, `Entrée` | La légende s'affiche sous l'image |
| Double-cliquer l'image | Visionneuse plein écran. `Échap` la ferme |
| Ouvrir `page.md` dans un éditeur de texte | `![texte](assets/nom.png#largeur=66&align=droite "Légende")`. Pleine largeur et centrée : pas de fragment |
| Supprimer une image de la page, puis dans les réglages, « Images inutilisées », « Chercher » | Le fichier de l'image retirée est listé. « Montrer » l'ouvre dans le gestionnaire de fichiers. Rien n'est supprimé |

## 4. Callout

| Manipulation | Attendu |
|---|---|
| `/callout`, `Entrée`, taper du texte avec du **gras** et du `code` | Encadré bleu « Info » avec 💡 |
| `Entrée` : un deuxième paragraphe dans le callout. `Entrée` sur une ligne vide | Le curseur sort du callout |
| Cliquer dans le callout : barre d'outils, menu « Info » : choisir « Attention », puis « Danger » | La couleur et l'icône changent |
| Bouton de l'icône : choisir 🚀, puis changer la nature | 🚀 reste |
| Menu de nature, « Retirer le callout » | Le texte reste, en paragraphes ordinaires |
| Ouvrir `page.md` dans un éditeur de texte | Un bloc ` ```notes-callout ` en YAML lisible : `type`, `icon` s'il a été choisi, `text` |

## 5. Une vraie page

Rédiger, ou reprendre d'AppFlowy, une vraie note technique d'une ou deux pages (une procédure du NAS, par exemple), avec du code, un tableau, une capture et un avertissement. Puis la relire.

Attendu : on ne bute sur rien, aucun texte ne change ou ne disparaît, et le fichier reste lisible dans un éditeur de texte.

Fermer et rouvrir l'application : la page est la même.
